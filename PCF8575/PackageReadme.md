# PCF8575

Кроссплатформенная .NET-библиотека для управления 16-битным расширителем GPIO PCF8575 через I2C. Пакет `Wastegate.Framework.Pcf8575` предоставляет типы в пространстве имен `PCF8575` и использует `System.Device.Gpio`.

## Подключение и инициализация

Установите NuGet-пакет `Wastegate.Framework.Pcf8575`, подключите микросхему к I2C и используйте ее адрес, установленный выводами адреса на вашей плате. Пример `0x20` приведен для иллюстрации; фактический адрес зависит от модуля.

Если имя шины не указано, библиотека использует I2C bus 1. Чтобы выбрать шину явно, передайте ее имя или путь, например `i2c1` или `/dev/i2c-1`:

```csharp
using System;
using PCF8575;

using IPcf8575 pcf8575 = new Pcf8575();
await pcf8575.Initialization("i2c1", address: 0x20);
```

`Initialization` открывает I2C-устройство и возвращает `Task<bool>`. Номер шины и адрес должны соответствовать конфигурации платы и ОС.

## Чтение и управление линиями

PCF8575 предоставляет 16 линий ввода-вывода. Состояние всех линий читается как массив из двух байтов. `SetPinState(ushort mask)` инвертирует состояния тех линий, которым соответствуют единичные биты маски; метод не задает абсолютный высокий или низкий уровень. `ResetState()` записывает высокий уровень на все линии.

```csharp
byte[] state = pcf8575.ReadPinState();
Console.WriteLine(BitConverter.ToString(state));

pcf8575.SetPinState(0b0000_0000_0000_0001); // Переключить линию, соответствующую биту 0.
pcf8575.ResetState();                       // Установить все линии в высокий уровень.
```

## Обработка прерываний

Чтобы получать новые состояния при изменениях на входах, укажите GPIO-пин, подключенный к выходу прерывания PCF8575, и подпишитесь на событие `PinChanged`. Событие передает считанное состояние двух портов. Опциональный `timeout` задает минимальный интервал между обработанными событиями; по умолчанию подавление событий не включено.

```csharp
using var pcf8575 = new Pcf8575();
pcf8575.PinChanged += pins => Console.WriteLine(BitConverter.ToString(pins));
await pcf8575.Initialization(
    "i2c1",
    address: 0x20,
    pinInterrupt: 17,
    timeout: TimeSpan.FromMilliseconds(10));
```

Убедитесь, что выбранный GPIO поддерживает обработку изменения уровня на вашей платформе. Событие вызывается для спадающего и нарастающего фронтов. При завершении работы освободите устройство через `Dispose()` или `using`.

## Ограничения платформы

Библиотека не настраивает частоту I2C: она определяется системным драйвером. Номера I2C-шины, адрес устройства и GPIO задаются согласно конкретной плате и ОС.
